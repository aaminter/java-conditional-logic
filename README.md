# Java Conditional Logic

![Java CI](https://github.com/aaminter/java-conditional-logic/actions/workflows/ci.yml/badge.svg)

Учебные упражнения по условным операторам Java.

## Темы
- `if / else`;
- сравнение числовых значений;
- логические условия;
- ветвление в зависимости от возраста, температуры и скорости.

## Запуск
Требуется JDK. Откройте проект в IntelliJ IDEA и запустите класс `main`.

## Статус
Учебная работа по основам Java. Примеры демонстрируют условную логику на простых сценариях.
